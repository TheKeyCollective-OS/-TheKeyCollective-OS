# Sprint 6C.1 — Kiki Companion Foundation

## Outcome

Kiki now lives globally across The Key Collective OS as a persistent, page-aware companion.

## Included

- Official Kiki artwork with a rich berry-plum body and champagne-gold glitter eyeshadow.
- Official Lulu variation with soft pink blush and a gentler expression.
- Persistent app-shell placement across all 14 routes.
- Page-specific, non-shaming dialogue using Kiki’s approved voice.
- Tap-to-talk behavior and timed autonomous check-ins.
- Settings for visibility, speech, activity frequency, surprises, and reduced motion.
- Automatic, Kiki, and Lulu companion-mode selection.
- Automatic Lulu transformation inside Lani’s Corner.
- Safe wandering movement across the lower screen instead of a fixed corner position.
- Mobile-safe positioning and accessible status messaging.
- A companion state structure ready for Lulu and Petal Mode.

## Character rule

- Kiki: glitter eyeshadow, nosy, goofy, sassy, energetic.
- Lulu: soft pink blush, thoughtful, gentle, nurturing. Lulu’s visual transformation is reserved for the Petal Mode phase.
